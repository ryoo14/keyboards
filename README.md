# rhyn47

rhyn47 is a mechanical keyboard I designed.

It comes in three models: standard, low-profile and low-profile with trackball.

Please refer to the README file located in each keyboard's folder.

## Common Across All Models

- USB-C connectivity
- Direct-mounted RP2040 on the PCB
- 47-key ortholinear layout
- Hot-swapping switch support
- Screwless design
- Can be placed on top of a laptop (so-called “Sonshi style”)
